Administration du site

Modifie les informations, ajoute directement les photos depuis ton appareil, puis télécharge site-data.json. Les photos choisies seront intégrées dans le JSON, donc tu n’auras pas à les téléverser séparément. Aucun jeton GitHub n’est nécessaire.

1. Charger les données actuelles

Le panneau tente de charger automatiquement les données publiques du site. Si cela ne fonctionne pas, tu peux ouvrir le fichier JSON de ton dépôt et le coller dans la zone ci-dessous.

Ouvrir site-data.json sur GitHub ↗

2. Modifier les textes et liens

3. Concerts et galerie

Modifie ces deux zones au format JSON. Les concerts doivent rester une liste entre crochets [ ]. Chaque photo de galerie doit comporter id, image, caption et alt. Tu peux sélectionner un fichier photo pour chaque image ci-dessous : elle sera intégrée au JSON.

4. Fichier JSON complet (optionnel)

Cette zone contient toutes les données du site. Tu peux la modifier directement si tu sais éditer du JSON. Si tu la modifies, elle sera utilisée à la place des champs au-dessus.

Après le téléchargement

  1. Ouvre le dépôt GitHub Bommers Crooners.
  2. Crée une nouvelle branche depuis main.
  3. Dans cette branche, remplace le fichier site-data.json par le fichier téléchargé.
  4. Ouvre une Pull Request vers main, vérifie les changements, puis fusionne-la pour publier.

Le fichier site-data.json contiendra les photos sélectionnées sous forme d’images intégrées (JPEG optimisés). Télécharge aussi index.html compatible et remplace les deux fichiers dans la même branche GitHub avant d’ouvrir ta Pull Request. Les photos déjà hébergées par URL restent des liens externes tant que tu ne les remplaces pas avec un fichier photo.
